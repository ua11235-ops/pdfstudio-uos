# 2026-10-27

## PDF Studio（UOS 版 PDF 编辑器）

从零开发了一个面向统信 UOS / Deepin 的桌面 PDF 编辑器，代码在 `pdfstudio-uos/`。

- 技术栈：Python 3.7+ / PyMuPDF / Qt（PyQt5 与 PySide6 双兼容，`qtcompat.py` 收敛差异）
- 架构：`core/` 完全不含 Qt（可命令行测试），`ui/` 只做展示与编排
- 功能：阅读缩放、缩略图/目录/注释侧栏、全文查找（含中文文字层容错）、
  高亮/下划线/删除线/手绘/图形/箭头/文本框/便签、改字（redact+重写）、
  页面插入删除旋转移动提取拆分合并（缩略图多选+右键批量）、水印、页码、
  加密解密、涂黑脱敏、表单填写、压缩、导出图片/文本/长图、打印、OCR
- 打包：`packaging/install.sh`（系统/用户两种模式 + 卸载）、`build_deb.sh`
- 测试：`tests/smoke_core.py` 26 项、`tests/ui_smoke.py` 14 项，全部通过

### 踩过的坑（值得记住）

1. **PyMuPDF `Document.move_page()` 对相邻页无效**，页序调整改用 `doc.select(order)`。
2. **`add_freetext_annot()` 会忽略 fill 颜色，且首尾字符被裁**，文本框改为
   `draw_rect` + `insert_textbox` 直接写入页面内容。
3. **`insert_textbox` 失败时仍会写入部分文字**，重复尝试会导致文字叠印，
   必须先算字号（`_fit_font_size`）再一次性写入。
4. **`QListWidget.clear()` 会触发 currentRowChanged**，重建缩略图时必须整体
   屏蔽信号，否则打开文档会跳到错误的页。
5. **Qt QSS 不支持 CSS 三角形**，spinbox/combobox 箭头要在运行时用 QPainter
   生成 PNG，再用 `image: url(...)` 引用；`height: 50%` 在 Fusion 下不生效，
   要写固定像素高度。
6. **offscreen 平台没有字体库**，截图中文会变方框；正确做法是真实平台 +
   `WA_DontShowOnScreen`，既能完成排版又不弹窗。

## 安装脚本重写（用户反馈「!! 缺少运行依赖： pymupdf」）

根因是旧脚本只在**第一个** `python3` 上做 `import` 检查，而依赖常常装在别的
解释器里：`pip3 install` 装进了 3.10 的用户目录而 `python3` 是 3.7；或者
普通用户 `pip install --user` 装完又 `sudo ./install.sh`，root 的 `HOME=/root`
看不到 `/home/xxx/.local`。旧脚本还只报错不安装、启动器写死 `python3`。

新版 `packaging/install.sh` 的做法：

- `find_pythons()` 扫全部 `python3.x`，用 `sys.executable`（**不能** `realpath`，
  否则会把 venv 抹掉导致误判缺依赖）去重
- `pick_ready()` 找装齐依赖的；`pick_target()` 按「已有依赖权重 100 + 版本号」评分
- 三级兜底：apt（`python3-pyqt5` + `python3-pymupdf`，失败再试 `python3-fitz`
  并 `apt-get update` 重试）→ pip（root 装系统、非 root `--user`，遇 PEP 668
  再 `--break-system-packages`）→ venv（`${PREFIX}/venv`，`--system-site-packages`）
- 按 Python 版本锁 PyMuPDF：3.7 → `pymupdf<=1.22.5`，3.8 → `<=1.23.26`
- 启动器写入**探测到的解释器绝对路径**，解释器被删时退回 PATH 里的 python3
- `--doctor` 只读诊断；`PDFSTUDIO_PYTHON=...` 强制指定解释器
- 修掉旧脚本的隐藏 bug：`--remove` 分支里 `MODE` 已被改成 `remove`，
  导致 root 权限检查永远不触发 —— 拆成 `MODE`（system/user）+ `ACTION`
  （install/remove/doctor）两个变量

`run.py` 也加了依赖自检：缺依赖时打印当前解释器路径 + 可直接复制的命令，
有 Qt 时还弹窗（桌面启动没有终端，stderr 看不见）。

### 这次又踩的坑

7. **`while read` 会丢弃没有换行结尾的最后一行**。`printf '%s'` 输出单条路径时
   循环体一次都不执行，`find_pythons` 必须以 `printf '%s\n'` 结尾。
8. **`${X:+$'\n'}` 写在双引号里不展开** ANSI-C 转义，会变成字面量 `$'\n'`。
   要拼多行用 `printf -v` 或直接写字面换行。
9. Windows 上 WorkBuddy 的 python 是**包装器**，`sys.executable` 会指向被包装的
   真实解释器，导致不同环境被去重成同一个 —— 只影响本机调试，Linux 上正常。
