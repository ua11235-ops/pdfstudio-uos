## PDF 工作台 1.0.0

面向 **统信 UOS / 深度 Deepin / 麒麟** 与 **Windows** 的轻量 PDF 编辑器。
纯 Python（PyMuPDF + Qt），体积小、启动快、不依赖任何商业组件。

### 下载哪个

| 你的系统 | 下载 | 说明 |
| --- | --- | --- |
| 统信 UOS / Deepin / 麒麟 | `PDFStudio-1.0.0-UOS-x86_64.tar.gz`（79 MB） | **含离线依赖**，解压即装，全程不需要联网 |
| Windows | `PDFStudio-1.0.0-Windows.zip`（43 MB） | 解压 → 双击「安装.bat」，不需要管理员权限，也不需要装 Python |

> 两个包大小差一倍多，原因是 Linux 那份把 PyQt5 + PyMuPDF 的 wheel 一起打进去了——
> UOS 的 apt 源要系统激活才能用，离线依赖是能装上的唯一保障。

### UOS 上安装

```bash
tar -xzf PDFStudio-1.0.0-UOS-x86_64.tar.gz
cd pdfstudio-1.0.0
sudo ./packaging/install.sh          # 装给所有用户
# 或者
./packaging/install.sh --user        # 只装给当前用户，不需要 root
```

装完在启动器里搜「PDF 工作台」。不熟悉命令行的话，解压后看包里的 `安装说明.md`。

启动不了先跑诊断（只读，不改动任何文件）：

```bash
./packaging/install.sh --doctor
```

### Windows 上安装

解压 → 双击「安装.bat」。装到 `%LOCALAPPDATA%\Programs\PDFStudio`，
会建快捷方式、关联 `.pdf`、在「应用和功能」里登记卸载入口。

### 功能

- **阅读**：连续滚动、10%~800% 缩放、缩略图/目录/注释侧栏、中文容错查找
- **批注**：高亮/下划线/删除线、画笔、矩形/椭圆/箭头、文本框、便签、擦除
- **改字**：擦除文字层后按原字号颜色重写，周围排版不变
- **页面**：插入/删除/旋转/移动/提取/拆分/合并
- **缩略图拖拽直接改页序**；空白处拖拽框选多页（两种手势互斥）
- **合并多个 PDF**：缩略图拖拽排序，页序表是唯一真相，反复调整不累积质量损失
- **文档处理**：水印、页码、加解密、涂黑脱敏、表单填写、压缩、导出、打印、OCR

### 已知限制

- **「改字」只能改有文字层的 PDF**。扫描件请先用「工具 → OCR 识别当前页」
- **涂黑不可恢复**，会真正删除底层文字和图形，操作前建议先另存备份
- Windows 的 `.pdf` 关联受 **UserChoice** 机制管辖：如果你的机器上已被 WPS 等占用，
  需要到「设置 → 默认应用」里手动改，这是 Windows 10/11 的限制，绕不过
