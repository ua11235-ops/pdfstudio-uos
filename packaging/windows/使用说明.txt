PDF 工作台  使用说明
================================================

一个在 Windows 上查看和编辑 PDF 的小工具。
和 UOS 版功能一致：注释、改字、插删页、旋转、水印、页码、
加密解密、涂黑、压缩、导出、打印。


一、安装
------------------------------------------------
1. 把压缩包解压到任意位置（比如桌面）。
2. 双击  安装.bat
3. 看到"安装完成"就好了。

装到哪：C:\Users\你的用户名\AppData\Local\Programs\PDFStudio
不需要管理员权限，不会弹 UAC。

安装会做四件事：
  · 把程序拷到上面那个目录
  · 建开始菜单和桌面快捷方式
  · 把 .pdf 文件关联到本程序（会先记住你原来的关联，卸载时还原）
  · 在「设置 → 应用」里登记一个卸载入口


二、重复安装 / 升级
------------------------------------------------
直接再双击一次  安装.bat  就行，会覆盖掉旧版本，不用先卸载。
你原来的 .pdf 关联记录不会被覆盖，卸载时照样能还原成最初始的样子。

不想建桌面图标：  安装.bat -NoDesktop
不想动 .pdf 关联：安装.bat -NoAssociate
只想看看会做什么：安装.bat -DryRun


三、打开 PDF
------------------------------------------------
· 双击桌面上的「PDF 工作台」
· 或者开始菜单里找「PDF 工作台」
· 或者直接双击任意 .pdf 文件
· 也可以把 PDF 拖进已经打开的窗口


四、把几个 PDF 合成一个
------------------------------------------------
· 菜单 文件 → 合并 PDF 文件…（快捷键 Ctrl+M）
· 点「添加」选几个 PDF，或者直接从文件夹把它们拖进窗口
· 右边那排缩略图就是合并后的样子：
    拖动缩略图   = 调整顺序（可以把 A 的某页拖到 B 的前面）
                   拖动时会有一条蓝色竖线，表示会插到哪儿
    选中后 Delete = 删掉这一页（按住 Ctrl 可以多选）
· 底下选好保存位置，点「开始合并」

原来的文件不会被改动，只是另外生成一个新的 PDF。


五、如果双击 PDF 还是用别的软件打开
------------------------------------------------
这是 Windows 的规则：你以前手动设过"始终使用某个程序打开"的话，
系统会记住那个选择，优先级比安装程序高。

改法：
  设置 → 应用 → 默认应用
  → 按文件类型指定默认应用
  → 找到 .pdf → 选「PDF 工作台」

只有第一次需要这么设，之后就一直生效了。


六、卸载
------------------------------------------------
两种方式，任选：
  · 设置 → 应用 → 应用和功能 → 找到「PDF 工作台」→ 卸载
  · 或直接运行安装目录里的  卸载.bat

卸载会删掉程序、快捷方式和文件关联，
并把 .pdf 还原成你安装前的样子。你的 PDF 文件本身不会被碰。


七、可能遇到的问题
------------------------------------------------
【双击安装.bat 一闪就没了】
  说明安装过程报错了，但窗口关得太快看不到。
  在这个文件夹的地址栏里输入 cmd 回车，然后敲：
      安装.bat
  这样报错会留在窗口里，照着改或者把文字发出来。

【安装时报"找不到 PDFStudio.exe"】
  按可能性从高到低，逐条对一下：

  ① 你是不是直接在压缩包里双击的？
     双击 zip 里的文件时，Windows 只把那一个文件解压到临时目录，
     程序本体还在压缩包里，当然找不到。
     → 右键 zip → 全部解压 → 进解压出的文件夹 → 再双击 安装.bat

  ② 解压出来的文件夹里，有没有一个叫 PDFStudio 的文件夹？
     它必须和 安装.bat 在同一层。没有的话就是没解压完整，重新解压一次。

  ③ 有 PDFStudio 文件夹，但里面没有 PDFStudio.exe？
     基本可以确定是杀毒软件把主程序隔离了，看下面那条。

  ④ 先确认你手上的 zip 是 51MB 左右的。
     如果只有几百 KB，那是给 Linux 用的源码包，里面没有 Windows 程序。

  安装脚本会自己把"它看到的目录内容"打印出来，照着那个就能判断是哪一种。
  如果程序确实在别的位置，也可以在命令行里手动指定：
      安装.bat -AppDir "D:\某个路径\PDFStudio"

【杀毒软件报毒 / 被删掉】
  这个程序是用 PyInstaller 打包的，这类"自解压 + 加载 DLL"的程序
  容易被启发式规则误判。它不是病毒。
  处理办法：在杀软里把这个文件夹加入信任/白名单，然后重新解压一次。

【提示"文件正在被其他程序使用"，保存失败】
  说明这个 PDF 正在别的阅读器里开着，或者网盘在同步它。
  关掉那个程序再保存，或者用「文件 → 另存为」换个文件名。

【OCR 识别用不了】
  OCR 需要系统里另外装 Tesseract（含中文语言包），没装不影响其它功能。


八、目录里都是什么
------------------------------------------------
  PDFStudio\          程序本体，整个文件夹都要保留
  PDFStudio\PDFStudio.exe   主程序
  安装.bat            安装
  install.ps1         安装脚本（安装.bat 会调用它）
  uninstall.ps1       卸载脚本
  卸载.bat            卸载
  使用说明.txt        本文件
